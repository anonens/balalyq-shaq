# Балалық шаққа саяхат

Іс-шараға шақырту, қатысушы іздеу, мультфильм постерлері және шағын ойындар бар статикалық сайт. HTML, CSS және JavaScript браузерде орындалады. Сервер, дерекқор немесе npm пакеттері қажет емес.

## Vercel-ге жариялау

1. [Vercel](https://vercel.com/new) → **Add New → Project** ашыңыз.
2. GitHub-тан `anonens/balalyq-shaq` репозиторийін импорттаңыз.
3. Production Branch ретінде `main` таңдаңыз.
4. Төмендегі параметрлерді тексеріп, **Deploy** басыңыз.

| Параметр | Мәні |
| --- | --- |
| Framework Preset | `Other` |
| Root Directory | Репозиторий түбірі (`./`) |
| Build Command | Бос; build орындалмайды |
| Install Command | Бос; dependency орнатылмайды |
| Output Directory | `.` |
| Environment Variables | Қажет емес; бос қалдырыңыз |

Бұл параметрлер `vercel.json` ішінде берілген. Build және Install Command үшін интерфейсте Override қажет болса, оны қосып, өрістерді бос қалдырыңыз. `index.html`, `three.min.js`, `posters/` және `fishkalar/` бір түбірден жарияланады. `main` тармағына келесі push жасалғанда Vercel сайтты автоматты түрде жаңартады.

`.vercelignore` жергілікті баптауларды және README файлдарын deployment-тен алып тастайды.

## Environment variables

**Қазіргі нұсқаға ешқандай environment variable қажет емес.** Кодта API кілті, backend URL, Firebase, Supabase немесе дерекқор қосылымы қолданылмайды. `.env` файлын жасаудың қажеті жоқ.

Іс-шара күні, мекенжайлар, ұйымдастырушы, қатысушылар және бағдарлама `index.html` ішіндегі `<script type="application/json" id="cfg">` блогында сақталады. Vercel-ге environment variable қосу бұл деректерді өзгертпейді.

## Іс-шара деректерін өзгерту

`index.html` ішіндегі `id="cfg"` JSON блогын өзгертіп, GitHub-қа commit/push жасаңыз:

- `start`: Алматы уақытымен күн мен уақыт, мысалы `2026-10-26T15:00:00+05:00`.
- `locations`: екі мекенжай, атауы, 2GIS сілтемесі және қажет болса жеке уақыты.
- `organizer`: ұйымдастырушының аты мен телефоны.
- `people`: `["Аты Жөні", 1, "Бөлім"]` түріндегі қатысушылар. Екінші мән — мекенжай ID-і (`1` немесе `2`); бөлім міндетті емес.
- `program`: `["Уақыт", "Атауы", "Сипаттамасы"]` жолдары.
- `demo`: шынайы қатысушылар тізімі дайын болғанда `false` қойыңыз. Қазіргі `true` режимі бетте `200` адам көрсетіп, 24 үлгі жазбаны пайдаланады.

Қазіргі «Баптаулар» панелі мен «Сақтау және жариялау» функциясы Claude-тың `window.claude` API-ына тәуелді. Vercel-де бұл API жоқ, сондықтан панель жасырын қалады. Деректерді жоғарыдағы JSON арқылы жаңартыңыз.

Ойын нәтижелері мен «Көрдім» белгілері әр адамның браузеріндегі `localStorage` ішінде сақталады; құрылғылар арасында ортақ дерекқор жоқ.

## Жергілікті тексеру

Репозиторий түбірінде:

```sh
python3 -m http.server 3000
```

Браузерде `http://localhost:3000` ашыңыз. Негізгі бет, Three.js және суреттер жергілікті файлдардан жүктеледі. Excel импорттау коды іске қосылса, SheetJS сыртқы CDN-нен алынады; бұл қалыпты Vercel бетінде жасырын admin панеліне ғана қатысты.

Активтер мен бастапқы дереккөздер туралы қосымша ақпарат: `README.txt`, `ASSET_SOURCES.json`.

Vercel құжаттамасы: [build параметрлері](https://vercel.com/docs/builds/configure-a-build), [vercel.json](https://vercel.com/docs/project-configuration).
