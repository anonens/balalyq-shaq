# Балалық шаққа саяхат

JUZ40 тимбилдингіне шақырту, қатысушы іздеу, жеке билет пен бағдарлама бар статикалық сайт. HTML, CSS және JavaScript браузерде орындалады. Сервер, дерекқор немесе npm пакеттері қажет емес.

## Шақырту құрылымы

- Басты бетте іс-шара күні, басталу уақыты, кері санақ, билет іздеу және бағдарламаға өту бар.
- Аты-жөнімен іздеу жеке билетті, мекенжай нөмірін, координаторды және 2GIS сілтемесін көрсетеді. Арнайы қонақтарға екі мекенжай да бірден көрсетілетін арнайы шақырту шығады (екі QR, екі 2GIS батырмасы). Билет стандартты браузер жүктеуі арқылы PNG болып сақталады.
- Бағдарламада уақыт, кезең және сипаттама ғана көрсетіледі.
- Рандом мультфильм: жергілікті 288 постерден біреуі көрсетіледі. Алғашқы естелік Disney / Pixar әлемінен басталады, одан кейін толық жинақ араластырылады. Бір айналымда постер қайталанбайды; каталог пен іздеу жоқ.
- Байланыс бөлімі мен соңғы шақыру қонақты ұйымдастырушыға не өз билетіне апарады.
- «Жылан» ойыны жиналмалы бөлімде қалды: батырмалар, пернетақта және экранды сипау арқылы басқарылады. Бөлімді жапқанда, ойын экраннан кеткенде немесе бет жасырылғанда үзіліске қойылады. Фишка, асық ату, квиз, үлкен 3D сөре және бұрынғы admin/publish панелі алынды.
- Төменгі шақыру ертегі саябағының стилінде. Саябақ 3D сахнаның төменгі төбесінде Three.js-пен салынған: қамал мен жұлдыз ізі, цирк шатыры, жүретін вагоны бар американ төбешігі, айналатын шолу дөңгелегі және карусель. WebGL болмаса, `index.html` ішіндегі SVG нұсқасы көрсетіледі. Билет батырмасы мен іс-шара күні HTML түрінде қалады.

## Фондағы 3D

Jake, Steve, Nokia, BMO және SpongeBob `nostalgia/models/` ішіндегі жергілікті GLB файлдарынан жүктеледі. Sega және Red шағын Three.js геометриясын қолданады. Creeper, Чупа-чупс және BMO қасындағы зырылдауық алынды. Бір жүктелген GLB ортақ кэште сақталады. Steve қаңқасы `SkeletonUtils.clone` арқылы бөлек көшіріледі, өлшемі нақты сүйек позасын ескеріп есептеледі. Jake қолдары модель жүктелгенде төмен түсіріледі; бастапқы GLB өзгертілмеген.

Фишкалар тек декор болып қалды: түрлі түсті бет және дәл сол суреттің көк нұсқасы. Hulk-та қосымша ATK/DEF жазуы жоқ. WebGL болмаса, жеңіл CSS/SVG көрінісі іске қосылады. `prefers-reduced-motion` ескеріледі.

Талдау мен өзгеріс себептері: [INVITATION_REVIEW.md](INVITATION_REVIEW.md). Активтер авторлары: [nostalgia/README.md](nostalgia/README.md).

## Vercel-ге жариялау

1. [Vercel](https://vercel.com/new) → **Add New → Project** ашыңыз.
2. GitHub-тан `anonens/balalyq-shaq` репозиторийін импорттаңыз.
3. Production Branch ретінде `main` таңдаңыз.
4. Төмендегі параметрлерді тексеріп, **Deploy** басыңыз.

| Параметр | Мәні |
| --- | --- |
| Framework Preset | `Other` |
| Root Directory | Репозиторий түбірі (`./`) |
| Build Command | Бос; build орындалмайды |
| Install Command | Бос; dependency орнатылмайды |
| Output Directory | `.` |
| Environment Variables | Қажет емес; бос қалдырыңыз |

Бұл параметрлер `vercel.json` ішінде берілген. Build және Install Command үшін интерфейсте Override қажет болса, оны қосып, өрістерді бос қалдырыңыз. `index.html`, `three.min.js`, `nostalgia.js`, `nostalgia.css`, `vendor/`, `nostalgia/`, `posters/` және `fishkalar/` бір түбірден жарияланады. `main` тармағына келесі push жасалғанда Vercel сайтты автоматты түрде жаңартады.

`.vercelignore` жергілікті баптауларды және README файлдарын deployment-тен алып тастайды.

## Environment variables

**Қазіргі нұсқаға ешқандай environment variable қажет емес.** Кодта API кілті, backend URL, Firebase, Supabase немесе дерекқор қосылымы қолданылмайды. `.env` файлын жасаудың қажеті жоқ.

Іс-шара күні, мекенжайлар, ұйымдастырушы, қатысушылар және бағдарлама `index.html` ішіндегі `<script type="application/json" id="cfg">` блогында сақталады. Vercel-ге environment variable қосу бұл деректерді өзгертпейді.

## Іс-шара деректерін өзгерту

`index.html` ішіндегі `id="cfg"` JSON блогын өзгертіп, GitHub-қа commit/push жасаңыз:

- `start`: Алматы уақытымен күн мен уақыт, мысалы `2026-10-26T15:00:00+05:00`.
- `locations`: екі мекенжай (`1` — Береговая, 6; `2` — Бекешева, 36), атауы, 2GIS сілтемесі және қажет болса жеке уақыты.
- `organizer`: байланыс блогындағы атау. Телефон бос болса, қонаққа өз координаторына жазу керектігі айтылады.
- `people`: `["Тегі Аты", 1, "Координатор"]` түріндегі қатысушылар. Екінші мән — мекенжай ID-і (`1` немесе `2`). Арнайы қонақтар үшін `[1,2]` жазылады: олардың шақыртуында екі мекенжай да көрсетіледі.
- `program`: `["Бөлім нөмірі", "Атауы", "Сипаттамасы"]` жолдары. Уақыт көрсетілмейді, бағдарлама 7 бөлімге бөлінген.
- `demo`: `false`. Нақты тізім Google Sheets кестесінен («ТИМБИЛДИНГ ШАҚЫРТУ») алынды.

Іс-шара деректері тек репозиторийдегі `cfg` JSON арқылы жаңартылады. Жеке билет иесінің аты мен «Жылан» рекорды осы браузердегі `localStorage` ішінде сақталады.

Қазіргі конфигурация: 24 қазан, 14:00; Береговая, 6 және Бекешева, 36; 200 қатысушы, оның ішінде екі мекенжайға да баратын 12 арнайы қонақ. Координаторлардың өз билетінде «Координаторың» жолы шықпайды.

## Жергілікті тексеру

Репозиторий түбірінде:

```sh
python3 -m http.server 3000
```

Браузерде `http://localhost:3000` ашыңыз. Негізгі бет, Three.js және суреттер жергілікті файлдардан жүктеледі. Бетке қажет кітапханалар мен модельдер жергілікті файлдардан жүктеледі.

Активтер мен бастапқы дереккөздер туралы қосымша ақпарат: `README.txt`, `ASSET_SOURCES.json`.

Vercel құжаттамасы: [build параметрлері](https://vercel.com/docs/builds/configure-a-build), [vercel.json](https://vercel.com/docs/project-configuration).
