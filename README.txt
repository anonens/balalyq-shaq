БАЛАЛЫҚ ШАҚҚА САЯХАТ — JUZ40 ТИМБИЛДИНГІ

Билет іздеу, бағдарлама, мекенжай, ұйымдастырушы және кездесуге шақыру. Фишка, асық ату, «Жылан», квиз, үлкен 3D сөре және бұрынғы admin панелі алынды.
Билет браузерден тікелей PNG ретінде жүктеледі. Environment variables қажет емес.

Кейіпкерлер тек фондық декор: Jake, Steve, Nokia, BMO, SpongeBob, Creeper, Sega және Red. Jake қолдары төмен түсірілген. Hulk фишкасындағы ATK/DEF мәтіні алынды; көк беті түрлі түсті бетпен сәйкес.

Шақырту талдауы: INVITATION_REVIEW.md.
Активтер авторлары: nostalgia/README.md, ASSET_SOURCES.json.
