МУЛЬТФИЛЬМ
Бір уақытта бір кездейсоқ постер көрсетіледі. «Басқа мультфильм» батырмасы келесісін ашады. Бүкіл жинақ бір рет көрсетіліп болғанша бір атау қайталанбайды.
«Көрдім деп белгіле» нәтижесі осы браузерде сақталады.

КӨЛЕМДІ ЗАТТАР
Бастапқы WebGL сахнасындағы теледидар, телефон, асық, сақа, фишкалар, спиннер, зырылдауық, Рубик текшесі, ұшақ, кәмпит, көпіршіктер мен әткеншек сақталған. WebGL қолжетімсіз болса, сол заттар жеңіл CSS 3D көрінісінде көрсетіледі.
