БАЛАЛЫҚ ШАҚҚА САЯХАТ — JUZ40 ТИМБИЛДИНГІ

Билет іздеу, бағдарлама, мекенжай, ұйымдастырушы және кездесуге шақыру. Фишка, асық ату, квиз, үлкен 3D сөре және бұрынғы admin панелі алынды. «Жылан» жиналмалы бөлімде қалды. Рандом мультфильм толық жергілікті жинақтан кезекпен шығады. Төменгі жақ референстегідей ертегі саябағы стилінде жасалған.
Билет браузерден тікелей PNG ретінде жүктеледі. Environment variables қажет емес.

Кейіпкерлер тек фондық декор: Jake, Steve, Nokia, BMO, SpongeBob, Sega және Red. Jake қолдары төмен түсірілген. Hulk фишкасындағы ATK/DEF мәтіні алынды; көк беті түрлі түсті бетпен сәйкес.
